B2B Numerical Processing

Supported linear systems. Processed offline. Verified for delivery.

MERCY Systems provides a straightforward file-in / verified-result-out numerical processing service for supported linear systems. Customers provide an approved, non-sensitive numerical workload. MERCY Systems performs the processing and verification offline and returns the agreed solution package.

How It Works

Three simple steps.

1

You Send

A supported Matrix Market coefficient matrix and right-hand side containing approved, non-sensitive numerical data.

2

We Process & Verify

MERCY Systems processes the accepted Ax=b workload offline and verifies the solution against the submitted numerical system.

3

You Receive

Your agreed solution package in practical formats:

  • solution.vec
  • solution.csv
  • solution.mtx

Plus agreed verification documentation.

Current Production Scope

Precisely defined service boundaries.

MERCY Systems currently provides specialized numerical processing for supported square linear systems of the form Ax=b.

  • Square linear systems
  • Up to 1,001 variables
  • Supported Matrix Market inputs
  • Offline numerical processing
  • Solution verification against the submitted system
  • Approved, non-sensitive and unrestricted workloads only

What this service is

A controlled numerical-processing service centered on the mathematical workload itself.

Sensitive domain context is not required for the numerical-processing service.

Output: processed solution files and agreed verification documentation.

Restricted-Input Service

Only approved, non-sensitive numerical workloads.
